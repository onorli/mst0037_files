# MST0037 course files

Public files for the course MST0037, linked from the QR codes in the Options booklet and lecture notes.

Files live in `files/`. Each spreadsheet has a landing page on GitHub Pages that works on a phone:
it shows the sheet as a table, opens the real file in Microsoft's online viewer, or downloads it.

    https://onorli.github.io/mst0037_files/<slug>/          landing page (QR target)
    https://raw.githubusercontent.com/onorli/mst0037_files/main/files/<filename>   direct download

The pages are generated by `build_pages.py` (standard library only). After changing or adding a
spreadsheet, run `python3 build_pages.py` and commit the result. New files need an entry in the
`PAGES` table at the top of the script.
