# MST0037 course files

Public files for the course MST0037, linked from the QR codes in the Options booklet and lecture notes.

Files live in `files/`. Each file is reachable without login at

    https://raw.githubusercontent.com/onorli/mst0037_files/main/files/<filename>

Scanning a QR code in the booklet downloads the file directly.

## Files expected by the booklet

| Booklet section | File |
|---|---|
| 1.1 Simple stock model | `files/simple_stock_model.xlsx` |
| 3.1 Call option price: replicating portfolio | `files/option_2per_replicate.xlsx` |
| 3.2 Call option price: risk-neutral approach | `files/option_2per_risk_neutral.xlsx` |
| 4.1 Stock price: more steps | `files/stock_more_steps.xlsx` |
| 4.2 Call option price: more steps | `files/option_more_steps.xlsx` |

To update a file, replace it under the same name and push. The QR codes keep working.
